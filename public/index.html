Jev probe

実キーで Jev に1往復し、認証と返り値の形を確かめる。ローカルの npm run probe と同じ検査。

probe を実行 較正を実行（samples.json 全件）
probe は1回につき Jev が1往復、較正はサンプル件数ぶん課金されます。較正は PROBE_TOKEN の設定が必須です。

動かない場合

  1. Vercel の Project Settings → Environment Variables に AI_GATEWAY_API_KEY があるか
  2. 足した後に 再デプロイしたか（環境変数はデプロイ時に焼き込まれる）
  3. AI Gateway にカード登録があるか（無料枠でも必須）
